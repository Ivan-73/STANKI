1. Как пользоваться справочником

Что внутри. Карточки сгруппированы по категориям и по производителю: одна карточка = один изготовитель и все позиции каталога, которые к нему относятся (это избавляет от дублирования одинаковых ссылок по 81 строке).

Блок «Официальные ссылки». Для каждого изготовителя указаны только те адреса, существование которых подтверждено. Формат строки: URL → что находится по ссылке → дата проверки → статус. Если страница не найдена, она не выдумывается: стоит пометка «страница не найдена», а при отсутствии сайта — поисковая ссылка.

Кнопки копирования. «📋 Копировать» — копирует один URL; «📋 Копировать все ссылки производителя» — все URL карточки; «📋 Копировать все ссылки справочника» — единый список (по одному URL в строке, без дублей). Работает и при открытии файла по file:// (fallback через скрытый textarea).

Важно. Домен подтверждается только там, где он получен из открытых источников в ходе проверки. Для мелких китайских заводов официальные сайты часто отсутствуют — это зафиксировано честно, а не заменено «правдоподобным» адресом.
